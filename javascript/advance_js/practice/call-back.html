🔁 JavaScript Callback Functions

📌 What is a Callback Function?

Definition: A callback function is a function passed as an argument to another function, which is then invoked inside the outer function to complete an action or routine.

Why use callbacks?

  • To make code modular and reusable
  • To run code after a task completes (especially with asynchronous code)

🧪 Basic Example


function greet(name, callback) {
  console.log("Hi " + name);
  callback();
}

function sayBye() {
  console.log("Bye!");
}

greet("Jack", sayBye);

// Output:
// Hi Jack
// Bye!

🔄 Anonymous Callback

You can also pass an anonymous function:


greet("Mukti", function() {
  console.log("Take care!");
});

// Output:
// Hi Mukti
// Take care!

⏱️ Asynchronous Callback Example

In real apps, callbacks are often used with asynchronous code like setTimeout, fetch, etc.


console.log("Start");

setTimeout(function() {
  console.log("This runs after 2 seconds");
}, 2000);

console.log("End");

// Output:
// Start
// End
// This runs after 2 seconds

📦 Real-World Use Case

Suppose you're fetching user data from an API and want to display it only after the data is loaded:


function fetchData(callback) {
  setTimeout(() => {
    console.log("Data fetched");
    callback();
  }, 1000);
}

function showData() {
  console.log("Now displaying data...");
}

fetchData(showData);

📘 Summary

  • A callback is a function passed into another function.
  • Used to run code after a task completes.
  • Common in async operations like API calls, event handling, and timers.
