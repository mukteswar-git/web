JavaScript Object Manipulation: CRUD Operations

This webpage explains how to Create, Read, Update, and Delete (CRUD) properties on JavaScript objects.

1️⃣ Create

Definition: Creating an object is the process of defining a new object literal with key-value pairs, or using a constructor.

Example:


// Creating an object using literal notation:
let person = {
  name: "Jack",
  age: 25,
  occupation: "Django Developer"
};

console.log(person); 
// Output: {name: "Jack", age: 25, occupation: "Django Developer"}

2️⃣ Read

Definition: Reading an object means accessing its properties using either dot notation or bracket notation.

Example:


// Using dot notation:
console.log(person.name); // "Jack"

// Using bracket notation:
console.log(person["age"]); // 25

3️⃣ Update

Definition: Updating an object involves modifying existing properties or adding new properties if they don’t exist.

Example:


// Updating an existing property:
person.age = 26;

// Adding a new property:
person.city = "Bangalore";

console.log(person);
/* Output:
{
  name: "Jack",
  age: 26,
  occupation: "Django Developer",
  city: "Bangalore"
}

4️⃣ Delete

Definition: Deleting involves removing a property from an object using the delete operator.

Example:


// Removing a property:
delete person.occupation;

console.log(person);
/* Output:
{
  name: "Jack",
  age: 26,
  city: "Bangalore"
}
*/

Real-world Scenario

Imagine you're building a Django backend that sends user data as JSON. On the client side, you might perform object manipulation to update the UI without reloading the page. Here’s a quick scenario:

  • Create: An object representing a new user is received.
  • Read: You display the user's name and age.
  • Update: When the user edits their profile, you update their properties.
  • Delete: If a user decides to remove their phone number, you delete that property before sending data back to the server.
