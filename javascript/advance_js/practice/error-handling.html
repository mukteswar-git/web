🛑 JavaScript Error Handling

📌 What is Error Handling?

Definition: Error handling is a way to catch and respond to errors without crashing your application. JavaScript uses the try...catch syntax to catch exceptions.

🧪 Basic try...catch

If an error occurs inside the try block, control is passed to the catch block.


try {
  let num = 10;
  console.log(num.toUpperCase()); // ❌ Error: toUpperCase is not a function
} catch (err) {
  console.log("⚠️ Error caught:", err.message);
}

// Output:
// ⚠️ Error caught: num.toUpperCase is not a function

📦 throw and custom errors

You can create and throw your own errors using throw.


function divide(a, b) {
  if (b === 0) {
    throw new Error("Division by zero is not allowed");
  }
  return a / b;
}

try {
  console.log(divide(10, 0));
} catch (e) {
  console.log("⚠️ Custom Error:", e.message);
}

✅ finally block

finally will always run whether or not an error occurred — great for cleanup.


try {
  console.log("Trying something risky...");
  throw new Error("Oops");
} catch (err) {
  console.log("Caught:", err.message);
} finally {
  console.log("Cleanup: This always runs.");
}

// Output:
// Trying something risky...
// Caught: Oops
// Cleanup: This always runs.

🧠 Real-World Example


function fetchUserData(userId) {
  try {
    if (!userId) throw new Error("User ID is required");
    console.log(`Fetching data for user ${userId}...`);
    // Imagine fetching from an API
  } catch (err) {
    console.log("❌ Failed to fetch user:", err.message);
  } finally {
    console.log("📡 Request ended.");
  }
}

fetchUserData();  // No ID passed
fetchUserData(101);

📘 Summary

  • try...catch handles runtime errors.
  • throw is used to trigger custom errors.
  • finally always runs for cleanup.
  • Error handling makes your code safer and more user-friendly.
