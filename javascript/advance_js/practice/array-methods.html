🧠 JavaScript Array Methods

🔁 forEach()

Definition: Executes a function for each element in the array. It does not return a new array.

Example:


const fruits = ["apple", "banana", "cherry"];

fruits.forEach(function(fruit) {
  console.log(fruit);
});
// Output:
// apple
// banana
// cherry

🔄 map()

Definition: Creates a new array by applying a function to each element of the original array.

Example:


const numbers = [1, 2, 3, 4];
const doubled = numbers.map(num => num * 2);
console.log(doubled); // [2, 4, 6, 8]

🧹 filter()

Definition: Creates a new array with only the elements that pass a certain condition.

Example:


const ages = [15, 22, 30, 17];
const adults = ages.filter(age => age >= 18);
console.log(adults); // [22, 30]

➕ reduce()

Definition: Reduces the array to a single value by applying a function to each item (e.g., sum or multiply).

Example:


const prices = [10, 20, 30];
const total = prices.reduce((sum, price) => sum + price, 0);
console.log(total); // 60
