🚀 ES6+ JavaScript Features

1. let & const

let and const are block-scoped variables. const cannot be reassigned.


let name = "Jack";
name = "Mukti"; // ✅

const age = 23;
// age = 24; ❌ Error

2. Arrow Functions

Arrow functions provide a shorter syntax for writing functions. They also don't have their own this.


// Regular function
function add(a, b) {
  return a + b;
}

// Arrow function
const addArrow = (a, b) => a + b;

console.log(addArrow(5, 3)); // 8

3. Template Literals

Template literals use backticks (`) and allow embedding expressions using ${...}.


const name = "Mukti";
const age = 23;
console.log(`My name is ${name} and I'm ${age} years old.`);
// Output: My name is Mukti and I'm 23 years old.

4. Destructuring

Destructuring allows unpacking values from arrays or objects into separate variables.


// Array destructuring
const numbers = [1, 2, 3];
const [first, second] = numbers;
console.log(first, second); // 1 2

// Object destructuring
const user = { name: "Jack", age: 20 };
const { name, age } = user;
console.log(name, age); // Jack 20

5. Spread Operator

The spread operator (...) expands elements of an iterable (like arrays or objects).


const arr1 = [1, 2];
const arr2 = [...arr1, 3, 4];
console.log(arr2); // [1, 2, 3, 4]

const obj1 = { a: 1 };
const obj2 = { ...obj1, b: 2 };
console.log(obj2); // { a: 1, b: 2 }

6. Rest Operator

The rest operator (...) collects multiple elements into one variable.


function sum(...nums) {
  return nums.reduce((acc, val) => acc + val, 0);
}

console.log(sum(1, 2, 3, 4)); // 10

7. Default Parameters

You can set default values for function parameters.


function greet(name = "Guest") {
  console.log(`Hello, ${name}`);
}

greet();         // Hello, Guest
greet("Mukti");  // Hello, Mukti

📘 Summary

  • let and const: Modern variable declarations
  • Arrow Functions: Short syntax, no own this
  • Template Literals: Embed variables in strings
  • Destructuring: Unpack values from arrays/objects
  • Spread: Expand elements
  • Rest: Collect elements
  • Default Params: Fallback values in functions
