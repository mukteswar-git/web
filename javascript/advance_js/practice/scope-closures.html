🧠 JavaScript Scope & Closures

📦 What is Scope?

Definition: Scope determines where variables and functions can be accessed in your code. JavaScript has three main types of scope:

  • Global Scope: Variables accessible from anywhere.
  • Function Scope: Variables declared inside a function.
  • Block Scope: Variables inside { } using let or const.

// Global Scope
let globalVar = "I am global";

function testScope() {
  let functionVar = "I am inside a function";
  console.log(globalVar);       // ✅ Works
  console.log(functionVar);     // ✅ Works
}

testScope();
console.log(globalVar);         // ✅ Works
// console.log(functionVar);    ❌ Error: Not defined outside

🔒 What is a Closure?

Definition: A closure is a function that "remembers" variables from its outer (lexical) scope, even after the outer function has finished running.

This is possible because functions in JavaScript form closures automatically when defined inside another function.


function outerFunction() {
  let counter = 0;

  function innerFunction() {
    counter++;
    console.log("Counter:", counter);
  }

  return innerFunction;
}

const myCounter = outerFunction(); // Returns inner function with closure
myCounter(); // Counter: 1
myCounter(); // Counter: 2

Why it works: Even though outerFunction() is done executing, the inner function still remembers the counter variable.

🔧 Real-World Example of Closure


// Use case: private variable
function createUser(name) {
  let score = 0;

  return {
    getName: () => name,
    increaseScore: () => { score++; },
    getScore: () => score
  };
}

const user = createUser("Jack");

console.log(user.getName());   // "Jack"
console.log(user.getScore());  // 0
user.increaseScore();
user.increaseScore();
console.log(user.getScore());  // 2

This pattern is often used to create private variables in JavaScript (since score is not accessible directly).
