JavaScript Functions

Learn how to write and use functions in JavaScript

1. Function Declaration

Standard way to define a function. Can be called before it's defined due to hoisting.

function greet(name) {
  console.log("Hello, " + name + "!");
}

greet("Mukti");

2. Function Expression

Functions can be assigned to variables. Not hoisted.

const greet = function(name) {
  console.log("Hi, " + name + "!");
};

greet("Tripathy");

3. Arrow Functions (ES6+)

Shorter syntax for writing functions. Best for concise functions.

const greet = (name) => {
  console.log("Hey, " + name + "!");
};

greet("Mukti");

4. Arrow Function Shortcuts

If there's only one parameter and one line return, you can shorten it.

const square = x => x * x;
console.log(square(5)); // 25

5. Returning Values

Functions can return values using the return keyword.

function add(a, b) {
  return a + b;
}

let result = add(3, 4);
console.log(result); // 7

6. Default Parameters

Provide default values for function parameters.

function greet(name = "Guest") {
  console.log("Welcome, " + name);
}

greet();           // Welcome, Guest
greet("Mukti");    // Welcome, Mukti
