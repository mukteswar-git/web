JavaScript Arrays & Objects

Store and manage data using powerful JS structures

1. Arrays

Arrays hold multiple values in a single variable. They are ordered and indexed.

let fruits = ["apple", "banana", "mango"];
      console.log(fruits[0]); // apple
      console.log(fruits.length); // 3

2. Common Array Methods

let numbers = [1, 2, 3, 4, 5];

  numbers.push(6);        // Add to end
  numbers.pop();          // Remove from end
  numbers.shift();        // Remove from start
  numbers.unshift(0);     // Add to start
  numbers.includes(3);    // true
  numbers.indexOf(4);     // 3

3. Looping Through Arrays

let colors = ["red", "green", "blue"];

for (let i = 0; i < colors.length; i++) {
  console.log(colors[i]);
}

colors.forEach(color => {
  console.log(color);
});

4. Objects

Objects store data in key-value pairs.

let person = {
  name: "Mukti",
  age: 23,
  isStudent: true
};

console.log(person.name);  // Mukti
console.log(person["age"]); // 23

5. Updating & Adding Properties

person.age = 24;
person.city = "Bhubaneswar";

console.log(person);

6. Looping Through Objects

for (let key in person) {
  console.log(key + ": " + person[key]);
}
