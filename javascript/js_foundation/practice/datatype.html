JavaScript Data Types

Understand the different types of data you can work with in JavaScript

Primitive Data Types

  • String – Textual data, e.g., "Hello"
  • Number – Integer or floating-point, e.g., 42, 3.14
  • Boolean – Logical value: true or false
  • Undefined – A variable declared but not assigned
  • Null – Represents intentional absence of any value
  • BigInt – For very large integers
  • Symbol – Unique and immutable value used as object key
let name = "Jack";        // String
let age = 23;             // Number
let isStudent = true;     // Boolean
let address;              // Undefined
let value = null;         // Null
let bigNumber = 1234567890123456789012345678901234567890n; // BigInt
let uniqueId = Symbol("id"); // Symbol

Non-Primitive (Reference) Data Types

  • Object – A collection of key-value pairs
  • Array – An ordered list of values
  • Function – A block of reusable code
let person = {
  name: "Mukti",
  age: 23
}; // Object

let colors = ["red", "green", "blue"]; // Array

function greet() {
  return "Hello!";
} // Function

Type Checking

You can use the typeof operator to check the data type:

console.log(typeof "Hello");  // string
console.log(typeof 42);       // number
console.log(typeof null);     // object (this is a known JS quirk)
console.log(typeof undefined); // undefined
