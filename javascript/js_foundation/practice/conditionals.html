JavaScript Conditionals

Make decisions in code using conditional statements

1. if Statement

Executes a block of code if a specified condition is true.

let age = 18;
if (age >= 18) {
  console.log("You are eligible to vote.");
}

2. if...else Statement

Executes one block if true, another if false.

let isRaining = true;

if (isRaining) {
  console.log("Take an umbrella!");
} else {
  console.log("Enjoy the sunshine!");
}

3. if...else if...else

Tests multiple conditions in sequence.

let score = 75;

if (score >= 90) {
  console.log("Grade: A");
} else if (score >= 80) {
  console.log("Grade: B");
} else if (score >= 70) {
  console.log("Grade: C");
} else {
  console.log("Grade: D");
}

4. switch Statement

Performs different actions based on different conditions.

let day = "Tuesday";

switch (day) {
  case "Monday":
    console.log("Start of the week");
    break;
  case "Tuesday":
    console.log("Second day of the week");
    break;
  case "Friday":
    console.log("Almost weekend!");
    break;
  default:
    console.log("Just another day");
}

5. Ternary Operator

Short-hand way to write if...else in one line.

let age = 17;
let result = (age >= 18) ? "Adult" : "Minor";
console.log(result);
