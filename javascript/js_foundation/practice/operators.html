JavaScript Operators

Understand the different types of operators used in JavaScript

1. Arithmetic Operators

  • + Addition
  • - Subtraction
  • * Multiplication
  • / Division
  • % Modulus (Remainder)
  • ** Exponentiation
  • ++ Increment
  • -- Decrement
let x = 10, y = 3;
console.log(x + y); // 13
console.log(x % y); // 1
console.log(x ** y); // 1000

2. Assignment Operators

  • = Assign value
  • += Add and assign
  • -= Subtract and assign
  • *= Multiply and assign
  • /= Divide and assign
let a = 5;
a += 3;  // a = a + 3
console.log(a); // 8

3. Comparison Operators

  • == Equal to (loose)
  • === Equal to (strict)
  • != Not equal to (loose)
  • !== Not equal to (strict)
  • > Greater than
  • < Less than
  • >= Greater than or equal
  • <= Less than or equal
console.log(5 == "5");  // true
console.log(5 === "5"); // false
console.log(7 > 3);     // true

4. Logical Operators

  • && Logical AND
  • || Logical OR
  • ! Logical NOT
let isAdult = true;
let hasID = false;

console.log(isAdult && hasID); // false
console.log(isAdult || hasID); // true
console.log(!isAdult);         // false

5. String Concatenation Operator

The + operator can also be used to concatenate strings.

let firstName = "Mukti";
let lastName = "Tripathy";
console.log(firstName + " " + lastName); // Mukti Tripathy

6. Ternary Operator

Short form of an if...else condition.

let age = 18;
let status = (age >= 18) ? "Adult" : "Minor";
console.log(status); // Adult
