JavaScript Variables

Learn how to declare and use variables in JavaScript

What are Variables?

Variables are containers for storing data values. In JavaScript, you can declare a variable using: var, let, or const.

1. var

var is function-scoped and was traditionally used before ES6. It can be re-declared and updated. 

var name = "John";
console.log(name);

2. let

let is block-scoped and allows you to update (but not re-declare in the same scope). 

let age = 25;
age = 30;
console.log(age);

3. const

const is block-scoped like let, but you cannot reassign it. Use it for values that shouldn't change. 

const PI = 3.14159;
console.log(PI);

Best Practices

  • Prefer const by default.
  • Use let when you expect the value to change.
  • Avoid var unless working with legacy code.
