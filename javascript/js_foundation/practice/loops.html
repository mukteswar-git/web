JavaScript Loops

Repeat actions using different types of loops in JavaScript

1. for Loop

Use when the number of iterations is known.

for (let i = 1; i <= 5; i++) {
  console.log("Number: " + i);
}

2. while Loop

Use when the condition should be checked before the loop starts.

let i = 1;
while (i <= 5) {
  console.log("While Loop: " + i);
  i++;
}

3. do...while Loop

Runs the block at least once before checking the condition.

let j = 1;
do {
  console.log("Do While: " + j);
  j++;
} while (j <= 5);

4. for...of Loop

Used to loop through values of iterable objects like arrays.

let colors = ["red", "green", "blue"];
for (let color of colors) {
  console.log(color);
}

5. for...in Loop

Used to loop through keys in an object.

let person = { name: "Mukti", age: 23 };
for (let key in person) {
  console.log(key + ": " + person[key]);
}

6. break & continue

  • break: Exits the loop early
  • continue: Skips the current iteration
for (let i = 1; i <= 5; i++) {
  if (i === 3) continue;
  if (i === 5) break;
  console.log(i);
}
