# HTML, CSS & JavaScript Learning Projects Plan

## Goal
Build 5–7 projects to gain a strong foundation in HTML, CSS, and basic JavaScript.

---

## Project List

### 1. Personal Portfolio Website  
- **Skills:** Semantic HTML, CSS layouts (Flexbox/Grid), responsive design  
- **Focus:** Sections, navigation bar, footer, media queries

### 2. Blog Homepage (Static)  
- **Skills:** Card layouts, typography, images, CSS grids  
- **Focus:** Spacing, color schemes, fonts

### 3. Contact Form Page  
- **Skills:** HTML forms, input fields, buttons, basic JavaScript validation  
- **Focus:** Form structure, accessibility, event handling

### 4. Responsive Navbar with Dropdown  
- **Skills:** CSS positioning, hover effects, JavaScript event listeners  
- **Focus:** Responsive navigation menu, dropdown toggling

### 5. Image Gallery or Card Grid  
- **Skills:** CSS Grid/Flexbox, hover effects, JavaScript DOM manipulation  
- **Focus:** Modal popup, image interaction

### 6. To-Do List (Simple JavaScript App)  
- **Skills:** JavaScript variables, functions, DOM manipulation, event handling  
- **Focus:** Dynamic UI updates, adding/editing/deleting tasks

### 7. Landing Page (Product or Event)  
- **Skills:** Responsive layout, CSS animations/transitions, JavaScript scroll events  
- **Focus:** Calls-to-action, smooth scrolling

---

## Learning Tips

- Write semantic, clean HTML and CSS first.
- Make sure all projects are responsive and look good on mobile.
- Use basic JavaScript to add interactivity only after HTML and CSS are solid.
- Deploy your projects online using GitHub Pages or Netlify.
- Document your projects with README files.
- Try to build each project from scratch to improve problem-solving.
