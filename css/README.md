# 🎨 Mukteswar's CSS Learning Roadmap

Welcome to my personal CSS learning journey! I’m comfortable with HTML, but CSS used to feel confusing — so I’ve created a structured learning plan to make things click. This roadmap breaks CSS into 5 levels with clear goals and practice tasks.

---

## 🧱 Level 1: CSS Basics (Get Comfortable)

### 📘 Topics
- What is CSS?
- Inline, Internal, External CSS
- CSS Syntax (selector, property, value)
- Color values: name, hex, rgb(), hsl()
- Units: px, em, %, rem

### ✅ Practice
- Style an HTML page with text color, background, and font changes.
- Create and link an external CSS file.

---

## 🎨 Level 2: Styling Text and Box Model

### 📘 Topics
- Fonts: `font-family`, `font-size`, `font-weight`, `line-height`
- Text alignment and decoration
- Box Model (💡 crucial concept): `margin`, `padding`, `border`
- Width and height
- Background styling (color, images, repeat, position)

### ✅ Practice
- Build a styled card layout (like a product box).
- Try Google Fonts and custom font styles.

---

## 📦 Level 3: Layout & Positioning

### 📘 Topics
- `display`: block, inline, inline-block, none
- `position`: static, relative, absolute, fixed, sticky
- Float and clear (older but useful)
- **Flexbox** (🔥 must learn)
- CSS Grid (for advanced layout control)

### ✅ Practice
- Create a two-column layout with Flexbox.
- Center elements using Flexbox.
- Use [Flexbox Froggy](https://flexboxfroggy.com) to master Flexbox interactively.

---

## 🔍 Level 4: Advanced Selectors & Pseudo-classes

### 📘 Topics
- `:hover`, `:focus`, `:nth-child()`, `:first-child`
- Combinators: `*`, `>`, `+`, `~`
- Attribute selectors (e.g., `[type="text"]`)
- `!important` – use wisely

### ✅ Practice
- Style a button that changes color on hover.
- Style odd and even list items.
- Highlight specific inputs using attribute selectors.

---

## 📱 Level 5: Responsive Design & Effects

### 📘 Topics
- CSS Transitions
- Media Queries: `@media`, min-width, max-width
- Viewport units: %, `vw`, `vh`
- Responsive layout techniques

### ✅ Practice
- Make a responsive navigation bar.
- Create a grid of cards that adapts on smaller screens.

---

## 💬 Final Note

Don’t memorize. Build! Practice daily. Google is your best friend. Understanding comes with doing.

Let’s go from “CSS doesn’t make sense” to “CSS is fun and powerful!”
