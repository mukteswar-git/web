## 📦 Level 3: Layout & Positioning

### 📘 Topics
- `display`: block, inline, inline-block, none
- `position`: static, relative, absolute, fixed, sticky
- Float and clear (older but useful)
- **Flexbox** (🔥 must learn)
- CSS Grid (for advanced layout control)

### ✅ Practice
- Create a two-column layout with Flexbox.
- Center elements using Flexbox.
- Use [Flexbox Froggy](https://flexboxfroggy.com) to master Flexbox interactively.
