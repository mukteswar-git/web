What is CSS?

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation (look and layout) of an HTML document. It controls how elements appear on the screen — including colors, fonts, spacing, positioning, and responsiveness.

CSS Syntax (selector, property, value)

What is CSS Syntax?

CSS syntax defines how you write styling rules. Each rule consists of a selector, followed by curly braces { }, containing one or more property-value pairs.

1️⃣ Selector

A selector targets the HTML element you want to style. It can be a tag name, a class, or an ID.

Example:

p {
    color: red;
  }

This targets all <p> tags.

2️⃣ Property

A property is the style feature you want to change, such as color, font-size, or margin.

3️⃣ Value

The value sets how that property should appear, like red, 16px, or center.

Color Values in CSS

In CSS, you can define colors in multiple formats depending on your needs. Here are the four most common types:

1️⃣ Color Name

Use predefined color names like red, blue, green, etc. 

h2 {
    color: red;
  }

Example: This text uses the color name red.

2️⃣ HEX Value

HEX (hexadecimal) values start with # followed by six digits. Example: #ff0000 (red). 

h2 {
    color: #00ff00;
  }

Example: This text uses HEX #00ff00.

3️⃣ RGB()

RGB stands for Red, Green, Blue. You define values from 0 to 255. 

h2 {
    color: rgb(0, 0, 255);
  }

Example: This text uses RGB rgb(0, 0, 255).

4️⃣ HSL()

HSL stands for Hue, Saturation, Lightness. Example: hsl(120, 100%, 50%) (green). 

h2 {
    color: hsl(120, 100%, 50%);
  }

Example: This text uses HSL hsl(120, 100%, 50%).

CSS Units: px, em, %, rem

CSS uses different units to define length, size, spacing, etc. The most common units are:

1️⃣ px (Pixels)

A pixel is a fixed unit of measurement. It doesn't scale based on other elements. Good for exact spacing. 

p {
    font-size: 20px;
  }

Example: This paragraph uses 20px font size.

2️⃣ em (Relative to Parent)

1em equals the font size of the parent element. If the parent font size is 16px, then 1.5em = 24px. 

p {
    font-size: 1.5em;
  }

Example: This is 1.5em inside a 16px parent.

3️⃣ % (Percentage)

Percentage is relative to the parent element's size. Commonly used for width, height, and margins. 

div {
    width: 50%;
  }
Example: This box is 50% wide.

4️⃣ rem (Root em)

1rem equals the font size of the root element (<html>). By default, it's 16px. 

p {
    font-size: 2rem;
  }

Example: This is 2rem = 32px (if root is 16px).
