Fonts: font-family, font-size, font-weight, line-height

font-family: Defines the font used for text. Example: font-family: 'Poppins', sans-serif;

font-size: Sets the size of the text. Example: font-size: 18px;

font-weight: Controls the boldness. Example: font-weight: 400; or font-weight: bold;

line-height: Controls the spacing between lines of text. Example: line-height: 1.5;

Text Alignment & Decoration

text-align: Aligns the text horizontally.
Values: left, right, center, justify
Example: text-align: center;

text-decoration: Adds decoration to text like underline or strike-through.
Values: none, underline, line-through, overline
Example: text-decoration: underline;

text-transform: Changes the casing of text.
Values: uppercase, lowercase, capitalize
Example: text-transform: capitalize;

Box Model: margin, padding, border

margin: Space outside the element. Creates distance between elements.
Example: margin: 20px;

padding: Space between the content and the border (inside the element).
Example: padding: 15px;

border: The visible edge around the element.
Example: border: 2px solid #1e3a8a;

🔁 The Box Model = Content → Padding → Border → Margin

Width & Height

width: Sets the horizontal size of an element.
You can use units like px, %, vw.
Example: width: 300px; or width: 50%;

height: Sets the vertical size of an element.
Use px, %, vh, etc.
Example: height: 150px;

💡 If content overflows, you may need to manage it with overflow.

Background Styling: Color, Images, Repeat, Position

background-color: Sets the background color of an element.
Example: background-color: #1e3a8a; (dark blue)

background-image: Adds an image as background.
Example: background-image: url('path-to-image.jpg');

background-repeat: Controls if/how background image repeats.
Values: repeat (default), no-repeat, repeat-x, repeat-y
Example: background-repeat: no-repeat;

background-position: Sets starting position of background image.
Values: center, top, bottom, left, right, or x/y positions.
Example: background-position: center;
