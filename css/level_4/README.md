## 🔍 Level 4: Advanced Selectors & Pseudo-classes

### 📘 Topics
- `:hover`, `:focus`, `:nth-child()`, `:first-child`
- Combinators: `*`, `>`, `+`, `~`
- Attribute selectors (e.g., `[type="text"]`)
- `!important` – use wisely

### ✅ Practice
- Style a button that changes color on hover.
- Style odd and even list items.
- Highlight specific inputs using attribute selectors.
